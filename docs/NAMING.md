# Project naming review

## Finding

The standalone name **Prism** conflicts with an established product in the same
broad production-tooling market. Prism Pipeline describes itself as software for
organizing and automating animation and VFX workflows, has operated since 2016,
and maintains the public `PrismPipeline/Prism` repository. This creates obvious
search, support, repository, and user-expectation ambiguity even though this
project is a programmable video editor rather than a VFX pipeline manager.

Primary evidence checked on 2026-11-25:

- <https://prism-pipeline.com/docs/latest/>
- <https://github.com/PrismPipeline/Prism>
- <https://prism-pipeline.com/about/>

## Three alternatives

1. **SequenceSmith** — emphasizes constructing repeatable timelines and recipes.
2. **CommandCut** — makes the shared command engine and editing purpose explicit.
3. **Framewright** — suggests deliberate, craft-oriented picture construction.

These are proposals only, not clearance conclusions. Before choosing one, check
trademarks, domains, package registries, source hosts, and adjacent media tools.
Per the project brief, no rename has been made.
