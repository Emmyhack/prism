# Feature status

Status vocabulary: Planned, In development, Implemented, Tested, Production
ready, Blocked. "Implemented" never implies the later states.

| Feature | Status | Evidence / limitation |
|---|---|---|
| Rust workspace | Tested | Builds with pinned Rust 1.94.1 |
| Exact rational time | Tested | Exact arithmetic, explicit tick rounding, exact nearest-grid snapping with tie policy, and a commutativity/reversibility property test pass |
| Typed IDs/project model | Tested | Domain validator covers identity, media references, time ranges, ordering, and overlap; object set remains incomplete |
| Typed command API | In development | Atomic batches, revision conflicts, dry-run, undo/redo, exact sequence and per-track duration evaluation, track locking/reordering, visibility/mute state, marker operations, clip duplication, ripple delete, transitions, and core insert/move/trim/split/delete commands tested |
| Script protocol | In development | Exact-time DTOs for current commands, API/revision checks, dry-run intent, executable JSON transaction validation/commit, track lock/reorder/visibility/mute parity, marker, clip-duplication, ripple-delete, and transition parity, recipe manifest/input validation with default materialization, equivalent Python/JavaScript/TypeScript builders, and validated non-mutating debugger steps/breakpoints are tested |
| Persistence | In development | SQLite v4 round trip with track visibility/mute state, sequence markers, and transitions; v1/v2/v3 migrations, forward-version refusal, integrity checks, Unix atomic saves, no-clobber recovery backups, revision-scoped autosave artifacts, bounded revision-aware background autosaving, deterministic matching-file retention, newest-first autosave candidate discovery, and validated no-clobber autosave recovery are tested; crash recovery UI remains pending |

| Derived cache foundation | In development | Versioned SHA-256 cache keys, sharded traversal-safe paths, no-clobber atomic artifact writes, finalized-entry lookup/read, explicit age/size eviction, bounded background write and eviction workers are implemented and tested; cache persistence policy and broader derived-media integration remain pending |
| Color transfer foundation | In development | Validated normalized sRGB, Rec.709, PQ, and HLG transfer functions, D65 primaries conversion, HDR static metadata, metadata-driven PQ/HLG Rec.2020-to-SDR display mapping, bounded linear-RGB grading, validated 1D/3D LUTs, and deterministic histogram/waveform/vectorscope accumulation are implemented and tested. | CPU compositing foundation | In development | Validated linear RGBA source-over compositing with Normal, Multiply, Screen, Additive, Overlay, and cross-dissolve operations is implemented and tested. Mask shapes/feathering/tracking integration, render-graph mask nodes, and GPU parity remain pending |
| Render graph foundation | In development | Typed source/transform/crop/color/effect/blend/transition/text/output nodes, kind-specific input-arity validation, deterministic dependency registration, missing/duplicate input validation, topological evaluation order, cycle detection, and a tested CPU source/blend/transition/output/color/opacity/blend-mode pixel executor are implemented; full-frame resources and GPU backend remain pending |
| Effects and tracking foundation | In development | Exact-time ordered scalar curves with duplicate/negative/non-finite validation, endpoint clamping, and deterministic linear interpolation are implemented and tested. A bounded grayscale CPU point tracker provides deterministic integer-pixel SAD block matching, stable tie-breaking, normalized similarity, and forward/backward consistency error with strict frame/patch validation; pyramidal, subpixel, perspective/planar, mask, persistence, and UI workflows remain pending |
| Export | In development | Validated MP4 output supports one visible video track with exact trims and black gaps; synchronized single-video/single-audio export builds and validates an AAC-muxed MP4 when plan durations match, including an opt-in real-FFmpeg fixture; exact audio-track plans and deterministic FFmpeg concat-filter generation preserve trims and silence gaps while rejecting muted tracks; typed YouTube 1080p/4K presets provide exact geometry, frame rate, and target video/audio bitrate settings; explicit bitrate arguments are validated and passed to both video-only and synchronized exports; a typed container/codec/profile policy validates structural compatibility against explicit runtime capabilities, discovers known codec families from runtime encoder/muxer names, and maps resolved policies to deterministic FFmpeg arguments; hidden-track rejection, command-built saved/reopened projects, source-range and single-track FFmpeg cancellation, and authoritative Studio progress, failure, lifecycle, background execution, and cooperative cancellation boundaries are implemented and tested; request-level policy selection, configured worker launch from the graphical UI, and packaged encoder distribution remain pending |
| Audio foundation | In development | Allocation-free stereo gain/pan processing, routed multitrack mixing with mute state, indexed bus routing with per-bus gain/pan/mute controls, linear fades, equal-power crossfades, peak/RMS and dBFS analysis, deterministic peak normalization, mono and interleaved-stereo waveform min/max/RMS generation with peak dBFS conversion, block linear resampling, stateful streaming phase continuity, attack/release dynamics compression, hard limiting, stateful one-pole low/high-pass filtering, a stateful stereo feedback delay, and offline 48 kHz stereo BS.1770/EBU R128 integrated-LUFS metering with K-weighting and absolute/relative gates are implemented and unit tested; realtime device I/O, multichannel/sample-rate-general loudness metering, richer effects, and plugin hosting remain pending |
| Headless CLI | In development | No-clobber project creation, recovery backup, revision-scoped autosave and newest-first autosave listing, validated no-clobber autosave recovery, inspected-media sequence creation, versioned inspection including markers and transitions, recipe validation, explicit-FFmpeg proxy generation, typed video-track export, preset-driven YouTube 1080p/4K video export, synchronized single-video/single-audio export, track lock/reorder/visibility/mute, marker add/delete, clip duplication, ripple delete, transition add/delete, and command-backed video/audio clip insertion plus video movement, trimming, splitting, and deletion are tested |
